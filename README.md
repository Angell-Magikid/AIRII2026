# AIRII 2026 — AI Robotics Innovation Institute

Official website for AIRII (AI Robotics Innovation Institute).

## Structure

```
├── index.html          Home page
├── about.html          About / Mission / Team
├── workshop.html       Workshops
├── competition.html    Competitions
├── innovation.html     Innovation incubator
├── curriculum.html     Curriculum
├── training.html       Teacher training
├── shop.html           Shop
├── blog.html           Blog listing
├── blog-detail.html    Blog article
├── case-studies.html   Case studies listing
├── case-detail.html    Case study detail
├── css/
│   └── style.css       Global styles
├── js/
│   └── main.js         Interactive scripts
└── images/             All images and assets
```

## Tech Stack

- Pure HTML / CSS / JavaScript
- No build tools required
- Google Fonts: Space Grotesk, Inter, JetBrains Mono

## Development

Just open `index.html` in a browser. Or run a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
